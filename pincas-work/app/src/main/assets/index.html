גיבוי ושחזור
📖 חוברת הפעלה — גיבוי ושחזור

גיבוי נתונים: שומר תנועות, קטגוריות, החודש והשנה וגודל התצוגה. בכל לחיצה נוצר קובץ JSON חדש עם תאריך ושעה; גיבויים קודמים נשמרים.

גיבוי תוכנית: שומר עותק APK של הגרסה המותקנת. אם אותה גרסה כבר קיימת ותקינה בתיקייה, היא לא מועתקת שוב. תיקייה חדשה תקבל עותק גם אם הגרסה גובתה קודם במקום אחר.

Google Drive: בחר את התיקייה פעם אחת בהגדרות. כל גיבוי מנסה לשמור בטלפון וגם בתיקייה הנוספת. כישלון ביעד אחד אינו מבטל ניסיון שמירה ביעד השני.

שחזור: בחר קובץ JSON מהטלפון או מ־Drive ואשר את החלפת הנתונים. נתמכים גם הגיבויים הישנים של GS ו־HTML. כדי להתקין בטלפון חדש, מתקינים את ה־APK ואז משחזרים את קובץ הנתונים.

בחירת תיקיות: אם הגישה פגה או שהתיקייה הועברה, לחץ „בחר / שנה תיקייה”. בטלפון חדש בוחרים תיקיות מחדש. אם Android לא מאפשר לבחור את Download הראשית, בחר תיקיית משנה או השתמש בברירת המחדל.
